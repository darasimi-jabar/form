SAISIKA MEC SKILL SCHOOL — ADMISSION PROJECT
=============================================

FILES
-----
index.html   Main admission form and admin portal
style.css    Page layout and styling
script.js    Form submission, local records, admin login, search, print and export

HOW TO RUN
----------
1. Extract the ZIP file into a folder.
2. Keep all three files together in the same folder.
3. Double-click index.html to open it in Chrome, Edge, or Firefox.
4. Fill in the form and press Submit application.
5. Select Admin Portal in the navigation.
6. Demo password: hafeez
7. Use Open / Print on any record to open a print-friendly page.
8. Use Export JSON to save a backup of the local applications.

IMPORTANT LIMITATIONS
--------------------
This is a complete front-end demonstration project, not a production online admissions system.
Applications are stored in localStorage in the browser and on the device where they were submitted.
They will not automatically appear on another computer or phone.
Clearing browser data may delete the saved records. Export backups regularly.

The demo password is visible in script.js and is not secure authentication.
Do not use this project to collect real confidential student information online.
For a real school deployment, add a secure backend/database, server-side authentication,
HTTPS, access controls, and a privacy/data-retention policy.
